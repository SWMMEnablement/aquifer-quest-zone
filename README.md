Ponce Hydrology Lab

Ponce Hydrology Lab is a browser-based hydrology and hydraulics learning platform built with React, TypeScript, and Vite. It offers 33 interactive calculator and simulator modules spanning 11 domains, including engineering hydrology, open-channel hydraulics, hydromechanics, hydrogeology, hydrogeomorphology, hydroclimatology, and urban stormwater modeling with SWMM, along with a searchable calculator hub, a workflow builder for chaining modules together, and a connected knowledge graph of hydrology concepts.

The scientific content is based on the work of Prof. Victor Miguel Ponce of San Diego State University, with source material drawn from ponce.sdsu.edu. The project is for educational purposes and is not affiliated with SDSU.
